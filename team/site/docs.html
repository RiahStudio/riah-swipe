Publishing a deck

Agents and scripts publish through a project token. No account is needed on the sending side.

1. Get a token

Sign in, open the dashboard, create a project and press Get submit link. The link carries a token that starts with rswt_. Treat it like a password.

2. Create the deck

POST /api/projects/<projectId>/decks
Authorization: Bearer rswt_...
Content-Type: application/json

{
  "schema": "riah-swipe.deck/1",
  "decks": [{ "id": "round-1", "name": "Poster round 1", "kind": "image", "rev": 0 }],
  "cards": [{ "id": "c1", "deckId": "round-1", "title": "Poster A", "kind": "image", "media": "a.png" }]
}

The reply lists the new decks. Use the returned deck id in the next calls.

3. Upload each card's media

PUT /api/decks/<deckId>/cards/<cardId>/media
Authorization: Bearer rswt_...
Content-Type: image/png

(file bytes)

4. Publish

POST /api/decks/<deckId>/publish
Authorization: Bearer rswt_...

Publish last. Once every card's media is up, the deck appears in the reviewers' queue.

Reading verdicts

Signed-in reviewers swipe in the review app. Results for a deck are at GET /api/decks/<deckId>/results.
